# Zomfortress-Infection-Protocol
This is a fan-made game terminal-based endless turn-based game, which is set in the Team Fortress 2 universe.
You, as a Demoman character, have to survive dozens of neverending waves of zombies (their origin is explained in the lore of the game) . Plan your actions wisely, earn EXP, purchase upgrades for items and use your abilities strategically in order to survive as long as possible 
I am still developing this project, thus I am open for reviews, feedback and constructive criticism.

>**NOTE**:
>This game is non-commercial fan project inspired by Team Fortress 2, all assets and trademarks belong to Valve Corporation

# Features:
- ASCII graphics
- Endless turn-based combat
- Multiple zombie types (some of them have unique attacks)
- Shop and upgrade system
- in-game effects and visual effects
- hit/miss system
- critical hit system (as typical for TF2)
- dialogues based on Demoman's and Engineer's (telephone item) voice lines from TF2
